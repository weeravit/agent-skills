# Agent Skills

A collection of skills for AI coding agents.

## Skills

- **[grill-to-plan](skills/grill-to-plan/SKILL.md)** — orchestrator that grills a design in the language you pick (`grilling`), pressure-tests it against over-engineering (`ponytail`), then writes the confirmed plan in English to `docs/superpowers/plans/` (`superpowers:writing-plans`), with tests following `flutter-unit-test`.
- **[flutter-unit-test](skills/flutter-unit-test/SKILL.md)** — writes Flutter tests with Mocktail and Given-When-Then for the UChat Messenger project, with references for GetX, Isar, layer boundaries, and integration tests.
